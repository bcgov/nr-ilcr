# Grandfathered: versioned Flyway fixtures that carry seed rows, frozen as the baseline.
#
# The 2026-08-20 decision (docs/decisions/flyway-test-fixture-strategy.md) moved seed data out of the
# versioned namespace and into repeatable R__ migrations. It did NOT convert the existing chain --
# "the existing chain freezes as the baseline" -- so a uniformly applied check would fail this whole
# tree on day one. Every filename below is a file that already contained INSERTs when the check was
# written; FlywayMigrationConventionTest exempts exactly these and nothing else.
#
# THIS LIST IS SHRINK-ONLY.
#
#   * Adding a line grandfathers a NEW versioned seed file. That is the escape hatch this convention
#     exists to close, so the diff has to be argued for in review. It is not forbidden -- it is meant
#     to be visible.
#   * Removing a line is the record that one more fixture moved to R__. Do it in the same commit.
#   * A line naming a file that no longer exists, or one that no longer contains INSERTs, FAILS the
#     build. The list cannot quietly rot. (This is not hypothetical: bcgov/nr-ilcr#367 was filed
#     citing V30__ilcr_mill_user_profile_xref.sql as one of three clean files, two days after
#     PR #356 deleted it.)
#
# NOT ALL 45 ARE PRE-DECISION. Three post-date it, and two of those are in breach of convention 1a
# as already written:
#
#   V20260821__tsa_tsb_code_table_dates_and_seeds.sql   landed 38 minutes BEFORE the decision merged
#   V20260822__seed_schedule6_correction_fixtures.sql   landed 2026-08-24, 53 INSERTs  <-- violation
#   V20260823__seed_print_schedule8_combined_fixture.sql landed 2026-08-25, 11 INSERTs <-- violation
#
# Those last two are the files that proved the convention needed a machine check at all, so the
# baseline exempts the very violations that motivated it. That is a deliberate scoping call, not an
# oversight: the guard exists to stop the NEXT one, and retro-converting fixtures 115 IT classes read
# from is a different and riskier piece of work. They are the obvious first withdrawals from this
# list. Recorded here rather than left for a reader to discover (code review, 2026-08-27).
#
# Baseline captured at nr-ilcr main 3be15fe, 2026-08-27 -- 45 entries. Generated, not hand-typed.
# This command matches what FlywayMigrationConventionTest.containsSeedDml() does -- all three INSERT
# forms plus MERGE, and comments stripped so a "-- INSERT INTO ... (moved to R__30_)" header does not
# count. An earlier version of this recipe grepped only 'insert into' over raw text; it produced the
# same 45 today but would have disagreed with the check the moment a MERGE-based fixture landed:
#
#   for f in V*.sql; do
#     sed -e 's:--.*::' "$f" | tr '\n' ' ' | sed -e 's:/\*[^*]*\*/: :g' \
#       | grep -qiE 'insert[[:space:]]+(into|all|first)|merge[[:space:]]+into' && echo "$f"
#   done
#
# Blank lines and #-comments are ignored -- leading or trailing, so an inline note after a filename
# is fine. A duplicated entry FAILS the build. See db/README.md conventions 1 and 1a.
